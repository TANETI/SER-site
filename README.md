# SER Site

세라프 프로젝트 공개 사이트의 배포 전용 저장소입니다.

| 경로 | 내용 |
| --- | --- |
| `index.html` | GitHub Pages 진입 페이지 |
| `CNAME` | 현재 임시 사용자 도메인 |
| `assets/css/` | 스타일시트 |
| `assets/js/` | 사이트 스크립트 |
| `assets/characters/` | 캐릭터별 공개 WebP 이미지 |
| `data/` | 사이트에서 읽는 캐릭터 데이터 |
| `guidebook/` | 세계관 가이드북 |

설정 원본과 제작 도구는 `SER` 저장소에서 관리합니다.
